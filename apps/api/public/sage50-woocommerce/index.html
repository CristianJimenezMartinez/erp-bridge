❌ Cuellos de Botella en Conectores Tradicionales para Sage 50

  • • Conectores web que exigen abrir el puerto TCP 1433 de SQL Server a Internet.
  • • Bloqueos de tabla (Table Locks) cuando administración factura mientras la web sincroniza.
  • • Descuadres de IVA y Recargo de Equivalencia al importar pedidos de distribuidores B2B.
  • • Problemas al cambiar de ejercicio contable en Sage 50 o gestionar múltiples almacenes.
  • • Cuotas mensuales abusivas por volumen de referencias o número de pedidos sincronizados.

✅ Ingeniería Bentian SQL Server Local-First

  • • Conexión interna en LAN (.\SAGE50 o .\SQLEXPRESS) con 0 puertos expuestos.
  • • Consultas diferenciales con hint WITH (NOLOCK) en menos de 25 ms sin bloqueos.
  • • Mapeo nativo de articulo, stocks, pvp, clientes, c_pediven y d_pediven.
  • • Cuadre fiscal al céntimo: IVA 21% / 10% / 4% y Recargo de Equivalencia (5,2% / 1,4% / 0,5%).
  • • Incluye Modo Evaluación Sandbox para probar sin tener Sage 50 instalado.

Preguntas Frecuentes sobre Sage 50 y Comercio Electrónico

¿Necesito abrir puertos en el router o exponer SQL Server a Internet? ▼

No. El Agente de Bentian se instala dentro de tu red local Windows y lee tu instancia de SQL Server localmente. Toda la comunicación con WooCommerce, PrestaShop o Shopify se realiza mediante peticiones salientes HTTPS autenticadas con firma criptográfica.

¿Qué ocurre cuando creamos un nuevo ejercicio contable en Sage 50? ▼

En Sage 50 cada ejercicio o grupo de empresa suele corresponder a una base de datos SQL Server (por ejemplo, 2026AA). Desde el panel local de Bentian puedes actualizar el nombre de la base de datos activa en un clic sin perder la configuración de series, almacenes ni el historial de pedidos sincronizados.

¿Cómo funciona el Modo Evaluación Sandbox para Sage 50? ▼

Al activar el switch Modo Evaluación (Sandbox Demo) en el panel del Agente (http://127.0.0.1:39281), Bentian emula en memoria las tablas articulo, stocks, pvp y c_pediven con un catálogo de prueba realista. Así puedes verificar la sincronización con tu tienda online antes de introducir las credenciales SQL de producción.
