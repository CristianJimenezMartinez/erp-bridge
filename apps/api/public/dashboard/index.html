Asistente de Configuración de Webhooks

Copia la URL canónica y registra el Webhook Secret en tu panel externo.

Shopify enviará una notificación HTTP POST con firma criptográfica en la cabecera x-shopify-hmac-sha256 cada vez que un cliente complete un pedido.

Protegido (Timing-Safe)

El secreto se almacena en memoria segura. En caso de regenerarlo, actualiza la firma en Shopify / Holded de inmediato.

Pasos para registrar el Webhook en Shopify
  1. Accede a tu panel de Shopify > Ajustes > Notificaciones > Webhooks.
  2. Pulsa en Crear webhook y selecciona el evento orders/create con formato JSON.
  3. Pega la URL del endpoint oficial de Bentian Bridge y guarda los cambios.
