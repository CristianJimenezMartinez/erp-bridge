Procedimiento de Puesta en Marcha

Paso 01
Descargar Agente

Descarga Bentian-Setup.exe en el equipo Windows donde se aloja Factusol.

Paso 02
Ejecutar Instalador

Completa el asistente. El servicio quedará residente en la bandeja del sistema de Windows.

Paso 03
Vincular Licencia y Base de Datos

Introduce la clave de activación y selecciona el fichero .accdb de Factusol.

Exclusiones Recomendadas en Antivirus y Windows SmartScreen

En caso de aviso de SmartScreen, selecciona "Más información" → "Ejecutar de todas formas". Añade %APPDATA%\Bentian Agent\ a las exclusiones del antivirus.
