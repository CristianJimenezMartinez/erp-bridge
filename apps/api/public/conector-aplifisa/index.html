Conector Aplifisa para tu tienda online

Para empresas que gestionan fontanería, climatización o suministros con Aplifisa. Bentian lee artículos y existencias con su reserva y registra los pedidos web en las tablas de pedidos de cliente.

Estado: Beta, en validación con clientes piloto

El perfil de Aplifisa contempla tres variantes de esquema (SQL, archivo local y catálogo) que todavía no coinciden entre sí y no se han contrastado con un Aplifisa real. Es el conector con más trabajo de armonización pendiente, así que lo ofrecemos solo para pilotos supervisados.

No ofrecemos garantías de sincronización en producción para este conector hasta completar la validación. Los conectores de Factusol y Sage 50 tienen su propia página de estado.

Cómo se conecta Bentian a Aplifisa

Según tu instalación, Aplifisa puede estar sobre SQL Server o sobre un archivo de base de datos. El adaptador acepta ambas vías.

  1. Con SQL Server, el agente usa la instancia que propone el asistente (.\APLIFISA o .\SQLEXPRESS) y la base GESTFUTURO u otra que indiques.
  2. Con archivo local, el agente abre la base .mdb o .accdb por OLEDB desde el equipo con acceso a la carpeta de datos.
  3. Se leen artículos y existencias del almacén configurado (por defecto el almacén 01).
  4. Los pedidos web se escriben en la cabecera y líneas de pedidos de cliente.

1

Código, nombre, familia, último coste, código de barras y artículos no dados de baja.

Cabecera y líneas de pedido con serie, número y observaciones.

Requisitos para Aplifisa

  • • Aplifisa (GestFuturo o Factus) con base de datos en SQL Server o archivo .mdb/.accdb accesible.
  • • Controlador OLEDB de Access (ACE) si trabajas con archivo.
  • • Usuario con permisos de lectura y de escritura en pedidos de cliente.
  • • Windows 10, Windows 11 o Windows Server para el agente.

Requisitos generales del agente en Requisitos del sistema.

Puntos que seguimos validando en Aplifisa

  • • Los nombres de columnas del catálogo y de los pedidos varían entre el modo SQL y el modo archivo.
  • • Al recibir un pedido, la reserva de stock puede afectar a todos los almacenes del artículo en vez de solo al elegido.
  • • El modo archivo local no serializa escrituras simultáneas.
  • • La asociación del pedido a un cliente concreto no está validada; se usa un cliente genérico.

Preguntas frecuentes sobre Aplifisa y comercio electrónico

¿Aplifisa, GestFuturo y Factus son lo mismo? ▼

En el perfil de Bentian se agrupan bajo «Aplifisa (GestFuturo / Factus)» porque comparten esquema previsto, pero no hemos podido comprobar todavía que todas las ediciones usen idénticos nombres de tabla. Es una de las cosas que buscamos validar.

¿Por qué hablan de stock «reservado»? ▼

Las existencias de Aplifisa incluyen una cantidad reservada para pedidos pendientes. El conector publica stock actual menos reservado, para evitar vender lo que ya está comprometido. Falta comprobar cómo recalcula Aplifisa esa reserva cuando entra un pedido externo.

¿Qué almacén se usa para el stock de la web? ▼

La lectura del catálogo apunta hoy al almacén 01. Poder elegir otro almacén en el panel y que el catálogo lo respete es una de las mejoras en curso.

¿Puedo conectar un Aplifisa que está en un NAS? ▼

En modo archivo, el agente admite rutas de red de Windows, incluidas UNC con espacios. Con ficheros compartidos entre varios puestos, hazlo primero sobre una copia: los bloqueos de acceso concurrente no están probados con Aplifisa.

¿Cuál es el proceso para entrar en el piloto? ▼

Contacta con nosotros con tu versión de Aplifisa y el tipo de base de datos. Te pedimos una copia sin datos sensibles para contrastar los nombres de tablas y columnas antes de hacer ninguna prueba de pedido.
