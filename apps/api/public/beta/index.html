Preguntas Frecuentes

¿Hasta cuándo dura la beta?

La Beta Pública Gratuita permanecerá completamente abierta y operativa para todas las empresas registradas hasta el 31 de Diciembre de 2026 a las 23:59:59. Avisaremos con antelación suficiente sobre las opciones de continuidad para el ejercicio 2027.

¿Es seguro para mis datos?

Totalmente. Operamos con Arquitectura Local-First: Tu base de datos de Factusol (.accdb) nunca se sube a servidores ajenos ni se replica en la nube de Bentian. La sincronización se realiza punto a punto directamente entre tu equipo y tu tienda online mediante HTTPS / TLS 1.3 sin intermediarios ni bases de datos de terceros intermediarias.
