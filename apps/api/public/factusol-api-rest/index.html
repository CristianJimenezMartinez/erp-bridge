Preguntas Frecuentes sobre la API de Factusol

¿Puedo integrar Factusol con aplicaciones móviles o tablets de almacén? ▼

Sí. Puedes desplegar el agente en un equipo Windows de la red local y consultar la API desde cualquier dispositivo móvil o terminal de mano conectado a la misma red Wi-Fi de la empresa.

¿Soporta creación de pedidos de venta (F_PCL) y clientes (F_CLI)? ▼

Totalmente. La API incluye endpoints POST para registrar pedidos completos con cabecera y líneas detalladas, aplicando tarifas por cliente, condiciones de pago y tipos de IVA oficiales.
