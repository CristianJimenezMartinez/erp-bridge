Ecosistema & Integraciones

Conectores de integración.

Arquitectura modular orientada a conectar sistemas de gestión locales con canales de venta y ERPs en la nube. Mostramos con honestidad lo que funciona hoy en producción y la ruta de expansión.

Factusol ERP

Lectura OLEDB de tablas F_ART, F_STO, F_CLI, F_PCL y F_FAC. Compatible con bases de datos Access (.accdb) en versiones 2024, 2025 y 2026 en local o red NAS.

Conector nativo: Docs Factusol
eCommerce ACTIVO 100%

Shopify GraphQL API

Conexión directa vía Shopify Admin API (GraphQL 2024-10+). Sincronización atómica de stock multiubicación (DISSTO) en lotes de 50 ítems, Webhooks reactivos en tiempo real (orders/create), control Token Bucket y mapeo de IVA español con Recargo de Equivalencia. Sin costes mensuales cloud.

Guía de integración: Ver Guía Shopify
Cloud ERP & Finanzas ACTIVO 100%

Holded Cloud ERP Gestoría Cloud

Enlace directo del almacén físico Factusol con la facturación y asesoría contable en la nube vía Holded REST API v1. Emisión automática de facturas de venta desde albaranes, sincronización de clientes, asientos contables en Libro Diario y protección anti-duplicados mediante customId. Cero doble picado manual.

Guía de integración: Ver Guía Holded
eCommerce ACTIVO 100%

WooCommerce

Conexión bidireccional por REST API v3 con autenticación HMAC. Sincronización de artículos, stock, variaciones, estados de pedido y clientes. Compatible 100% con High-Performance Order Storage (HPOS).

PrestaShop

Integración a través de conector PHP nativo y Web Services API (PrestaShop 1.7 / 8.x / 9.x). Operativo en producción para sincronización de catálogo, stock, combinaciones y pedidos.

Documentación: Ver Guía PrestaShop

SimplyGest Desktop DBISAM / API / MDB

Triple motor nativo: tablas DBISAM (Emp1\articulos.dat), Módulo SimplyGest Server API :56985 y Datos.mdb. Sincronización de catálogo, fotos automáticas, tallas/colores e inyección de pedidos en PEDIDOSC / PEDIDOS_VENTA sin bloquear el TPV.
