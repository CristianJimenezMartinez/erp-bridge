Conector de Sage 200 para tu tienda online

Bentian lee el catálogo y las existencias de la base de datos SQL Server de Sage 200 y registra los pedidos web como pedidos de cliente. El agente corre en tu servidor Windows y solo hace conexiones salientes hacia tu tienda.

Estado: Beta, en validación con clientes piloto

Las tablas y columnas de Sage 200 (CabeceraPedidoCliente, LineasPedidoCliente, AcumuladosStock) proceden de nuestro perfil de integración y todavía no se han contrastado con una instalación real de Sage 200. Antes de usarlo con datos de producción, pruébalo en el Modo Evaluación y en una copia de tu base de datos.

No ofrecemos garantías de sincronización en producción para este conector hasta completar la validación. Los conectores de Factusol y Sage 50 tienen su propia página de estado.

Cómo se conecta Bentian a Sage 200

Sage 200 almacena sus datos en Microsoft SQL Server, así que el adaptador usa la misma vía que otros ERP SQL de Bentian: una conexión directa a la instancia desde dentro de tu red.

  1. Instalas el agente de Bentian en el servidor (o en un PC con acceso a la instancia SQL de Sage 200). Las instancias que el asistente propone por defecto son .\SAGE200 y .\SQLEXPRESS.
  2. Indicas la base de datos, un usuario SQL y la empresa. Las lecturas de catálogo y stock se lanzan con WITH (NOLOCK).
  3. Eliges tarifa, almacén y serie de pedidos en el panel local del agente (http://127.0.0.1:39281).
  4. Los pedidos de WooCommerce, PrestaShop o Shopify se escriben en la cabecera y las líneas de pedido de cliente de Sage 200.

Qué sincroniza el conector de Sage 200

1

Catálogo de artículos

Código, descripción, familia, precio de venta, precio de compra y código alternativo de los artículos no obsoletos.

2

Existencias

Unidades de saldo menos unidades reservadas, leídas de los acumulados de stock del periodo vigente.

3

Pedidos de cliente

Cabecera y líneas del pedido web con ejercicio, serie y número, más las observaciones del pedido.

4

Modo Evaluación

Un catálogo de ejemplo (compresores, polipastos, enrolladores) para probar el flujo sin conectar a tu Sage 200.

Requisitos para Sage 200

  • • Sage 200 sobre SQL Server accesible por red local desde el equipo del agente.
  • • Usuario SQL con permiso de lectura y, para pedidos, de escritura en las tablas de pedidos.
  • • Windows 10, Windows 11 o Windows Server para el agente.
  • • Una copia de seguridad de la base de datos antes de la primera prueba con pedidos reales.

Requisitos generales del agente en Requisitos del sistema.

Puntos que seguimos validando en Sage 200

  • • El cliente del pedido y el código de empresa pueden no coincidir con tu configuración; hay que revisarlos en las pruebas.
  • • Con varios almacenes, el comportamiento del descuento de stock por almacén está en revisión.
  • • La numeración del pedido la calcula el conector; no usamos todavía el contador oficial de Sage 200.
  • • El nombre de la columna de acumulados de stock se ha de confirmar con tu versión.

Preguntas frecuentes sobre Sage 200 y comercio electrónico

¿Sage 200 y Sage Murano son el mismo producto para Bentian? ▼

Sí a efectos de conexión: el perfil se llama «Sage 200 (Sage Murano)» y trabaja sobre la base de datos SQL Server de la instalación. Lo que cambia entre versiones son los nombres exactos de tablas y columnas, y eso es lo que queremos contrastar con clientes piloto.

¿Funciona con Sage 200 en la nube? ▼

No. El conector actual necesita llegar a la instancia SQL Server de Sage 200, por lo que está pensado para instalaciones locales o servidores propios. No hay conexión por API de Sage 200 Cloud.

¿Qué pasa con la empresa y el ejercicio al registrar un pedido? ▼

El pedido se escribe con CodigoEmpresa y EjercicioPedido. El ejercicio se toma del año en curso. La detección automática de la empresa es uno de los puntos a validar, así que indícanos cuál usas durante el piloto.

¿Puedo probarlo sin tocar mi Sage 200? ▼

Sí. El Modo Evaluación Sandbox del agente simula un catálogo de Sage 200 y permite comprobar la conexión con tu tienda de pruebas sin abrir tu base de datos real.

¿Cómo entro en el piloto de Sage 200? ▼

Escríbenos desde el botón de contacto de esta página indicando tu versión de Sage 200 y tu tienda. Priorizamos a quienes puedan probar en una copia de la base de datos y compartir el esquema real de sus tablas de pedidos.
