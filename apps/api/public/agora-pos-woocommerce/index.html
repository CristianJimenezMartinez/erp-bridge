Preguntas Frecuentes sobre Ágora POS / Retail

¿En qué equipo se instala el Agente de Bentian cuando tenemos varios terminales TPV? ▼

Solo necesitas instalar el Agente en el terminal TPV principal que actúa como servidor de base de datos (.\SQLEXPRESS o .\AGORA) o en cualquier ordenador de backoffice dentro de la misma red local. Todos los cobros realizados desde los TPV secundarios se consolidan en esa instancia SQL y se sincronizan automáticamente con la web.

¿Cómo reservo stock para que la web no venda la última unidad expuesta en vitrina? ▼

Desde la configuración local de Bentian puedes establecer un Buffer de Stock de Seguridad (por ejemplo, 1 o 2 unidades) o bien sincronizar exclusivamente contra el almacén secundario de reserva, manteniendo el stock de vitrina protegido para el cliente presencial.

¿Ofrecéis acuerdos para distribuidores e instaladores de TPV Ágora? ▼

Sí. Contamos con un programa de partners y licencias Reseller multi-tenant que permite gestionar las tiendas conectadas de tus clientes desde un único panel centralizado y hacer demostraciones comerciales con el Modo Evaluación Sandbox.
