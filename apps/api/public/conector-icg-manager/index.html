Conector para ICG Manager y tu comercio online

Pensado para tiendas, hostelería y retail que gestionan sus artículos en ICG Manager o FrontRetail. Bentian lee artículos, precios y stock de SQL Server y escribe los pedidos web en las tablas de pedidos de venta.

Estado: Beta, en validación con clientes piloto

Los nombres de tablas y columnas de ICG (PEDVENTACAB, PEDVENTALIN, STOCKS, PRECIOSVENTA…) no están verificados contra una instalación real. Hemos detectado diferencias entre el perfil de lectura y el de escritura que seguimos corrigiendo, por lo que no recomendamos pedidos reales sin una fase de pruebas.

No ofrecemos garantías de sincronización en producción para este conector hasta completar la validación. Los conectores de Factusol y Sage 50 tienen su propia página de estado.

Cómo se conecta Bentian a ICG Manager

ICG guarda sus datos en SQL Server. El agente se conecta desde la red local de la tienda o la oficina, sin exponer la base de datos a Internet.

  1. Instalas el agente en un equipo Windows con acceso a la instancia de ICG. El asistente propone .\ICG y .\SQLEXPRESS.
  2. Configuras la base de datos (por defecto ICGManager), el usuario SQL y la tarifa de venta que quieres publicar.
  3. Eliges el almacén cuyo stock se envía a la web; en ICG los almacenes se identifican con códigos como 1 o 2.
  4. El agente publica el catálogo y registra los pedidos web como pedidos de venta de ICG.

1

Artículos y códigos de barras

Descripción, familia, último coste y código de barras desde las líneas de artículo.

2

Precios por tarifa

Precio neto por tarifa de venta (identificador de tarifa configurable).

3

Stock por almacén

Stock menos unidades pendientes de servir, por almacén.

4

Pedidos de venta

Cabecera y líneas del pedido con serie, número y observaciones.

Requisitos para ICG Manager

  • • ICG Manager o FrontRetail sobre SQL Server accesible desde la red local.
  • • Usuario SQL de solo lectura para el catálogo y, para pedidos, permiso de escritura en pedidos de venta.
  • • Conocer los códigos de tarifa y de almacén que quieres usar en la web.
  • • Windows 10, Windows 11 o Windows Server para el agente.

Puntos que seguimos validando en ICG

  • • Los artículos con tallas y colores pueden aparecer repetidos en el catálogo: la agrupación por variante está pendiente.
  • • Tarifa y almacén del catálogo aún no siguen siempre la configuración elegida en el panel.
  • • El cliente asignado al pedido es genérico; el alta o búsqueda de cliente por NIF no está validada.
  • • Si tus códigos de artículo contienen guiones, hay que comprobar cómo se interpretan en las líneas.

Preguntas frecuentes sobre ICG Manager y comercio electrónico

¿Sirve para FrontRetail y para ICG Manager o solo para uno? ▼

El perfil se ha escrito para ambos porque comparten la base de datos de gestión, pero solo hemos trabajado con el esquema previsto. Si usas HIOPOS o FrontRetail con una base distinta, dínoslo en el piloto.

Vendo ropa con tallas y colores. ¿Lo gestiona? ▼

Todavía no de forma fiable. Las tallas y colores se guardan en líneas de artículo y ahora mismo el catálogo puede generar filas repetidas. Es la mejora que más nos interesa validar con una tienda real de moda.

¿Se puede reservar stock cuando entra un pedido web? ▼

El conector escribe el pedido y tiene prevista la reserva de stock, pero ICG distingue entre pendiente de servir y asignado, y estamos comprobando qué campo debe actualizarse. Por eso la reserva no está garantizada en esta fase.

¿Qué ocurre si mi servidor ICG está en otra tienda? ▼

El agente debe llegar a la instancia SQL por red local o VPN de la empresa. No abrimos puertos hacia fuera. Si cada tienda tiene su propia base de datos, conviene un agente por base de datos.

¿Qué necesito para probarlo sin riesgo? ▼

Usa el Modo Evaluación Sandbox (catálogo de ejemplo de hostelería y frío) y, después, una copia de tu base de datos en un servidor de pruebas. No lances pedidos reales contra la base en producción durante la beta.
