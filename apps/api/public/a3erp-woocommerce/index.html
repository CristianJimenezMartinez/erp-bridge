El adaptador polimórfico de Bentian para a3ERP estructura las lecturas de catálogo y las escrituras de pedidos respetando las claves primarias, series analíticas y almacenes de Wolters Kluwer:

Tabla SQL a3ERP Campos Clave Mapeados Comportamiento en el Conector
dbo.ARTICULO CODART, DESCART, FAMILIA, PRCVENTA, TIPIVA, BLOQUEADO, PESO Sincronización de referencias activas, descripciones comerciales, tipos de IVA y precios base o tarifas asociadas.

Preguntas Frecuentes sobre Wolters Kluwer a3ERP

¿Cómo gestiona Bentian las series de pedidos de venta en CABEPEV? ▼

Puedes asignar una serie exclusiva para el canal online (por ejemplo, WEB o EC) en la configuración del Agente. Bentian calcula de forma transaccional el siguiente número de documento (NUMDOC) dentro de esa serie e inserta tanto la cabecera en CABEPEV como las líneas en LINEPEV.

¿Es compatible con autenticación de Windows y autenticación SQL Server? ▼

Sí. El conector soporta tanto Windows Integrated Security (SSPI) cuando el Agente corre en el propio servidor de a3ERP, como autenticación mediante usuario y contraseña de SQL Server con permisos acotados a la base de datos de la empresa.

¿Podemos validar el conector antes de pedir permisos al administrador de sistemas? ▼

Por supuesto. Activa el Modo Evaluación Sandbox tras instalar el Agente en cualquier PC Windows y podrás probar el ciclo completo de artículos, stock y pedidos contra tu tienda online usando el dataset simulado de a3ERP.
