Requisitos del Sistema, Certificación Softpedia y Entorno Operativo

Especificaciones técnicas oficiales verificadas por Softpedia (4.5/5 estrellas), requisitos de hardware (x64 nativo), permisos UAC (Instalador vs Portable), desinstalación limpia y configuración de red.

Bentian ERP Bridge es una aplicación de escritorio nativa de arquitectura x64 diseñada específicamente para entornos empresariales Windows. A diferencia de plugins web o scripts PHP que sobrecargan el servidor de la tienda, el agente de Bentian opera como un servicio local de alto rendimiento que consulta directamente el motor relacional de Factusol o SimplyGest en memoria, garantizando sincronizaciones en milisegundos con cero impacto en el mostrador.

2. Sistemas Operativos Compatibles (x64 Exclusivo)

Bentian ERP Bridge está compilado para arquitecturas nativas de 64 bits (x64). No es compatible con sistemas de 32 bits (x86), dado que los motores relacionales de Factusol/SimplyGest y el controlador Microsoft ACE OLEDB de 64 bits exigen espacio de direccionamiento completo de memoria. Es compatible con las siguientes versiones de Windows:

Sistema Operativo Arquitectura Estado de Soporte Notas Técnicas
Windows 11 (21H2 – 24H2) x64 exclusivamente Oficial / Recomendado Soporte nativo para Edge App Window aislado con aceleración hardware.
Windows 10 (1909 – 22H2) x64 exclusivamente Oficial Totalmente compatible con Microsoft Edge WebView2 / App nativa.
Windows Server 2022 / 2025 x64 exclusivamente Oficial / Servidor Óptimo para servidores dedicados de almacén o entornos virtualizados Hyper-V / Proxmox.
Windows Server 2016 / 2019 x64 exclusivamente Compatible Requiere instalación previa del navegador Microsoft Edge basado en Chromium.

3. Requisitos de Hardware Verificados por Softpedia

Gracias a su arquitectura de consultas compiladas OLEDB indexadas en memoria, el impacto del agente en la máquina es inferior al 0,5% de uso continuo de CPU. A continuación se detallan las especificaciones oficiales verificadas en la review de Softpedia:

Requisitos Mínimos (Softpedia)

Verificado
  • Arquitectura de Proceso: x64 nativa (Intel Core i3 / AMD Ryzen 3 o superior, 2 núcleos a 2.0 GHz).
  • Memoria RAM: Mínimo 500 MB de RAM libre (especificación oficial Softpedia; 4 GB de memoria física total en el sistema).
  • Espacio en Disco: 100 MB de espacio disponible en disco (para el instalador, los ejecutables compilados y el almacenamiento JSON atómico en AppData).
  • Pantalla: Resolución mínima de 1280x720 para la ventana de administración local.

Requisitos Recomendados

Alto Volumen
  • CPU: Intel Core i5 / AMD Ryzen 5 o superior (4 núcleos o más).
  • RAM: 8 GB o 16 GB de RAM física (óptimo para catálogos masivos >30.000 referencias y sincronizaciones multitarea).
  • Almacenamiento: Unidad SSD NVMe para acceso instantáneo a la base de datos .accdb en menos de 5 ms.
  • Red: Tarjeta de red Gigabit Ethernet (1 Gbps) si los datos del ERP (Factusol o SimplyGest) se alojan en un servidor NAS o recurso compartido SMB.

4. Privilegios UAC (Instalador vs Portable) y Desinstalación Limpia

Bentian ofrece dos modalidades oficiales de distribución adaptadas a las políticas de seguridad de cada empresa:

Instalador Oficial (.exe) Requiere Elevación Puntual

El asistente de instalación solicita elevación UAC única y exclusivamente para registrar la ejecución silenciosa en el arranque de Windows (HKCU\...\Run), crear accesos directos en el menú inicio y ubicar los binarios en Program Files.

Recomendado para puestos fijos de facturación, almacenes y servidores dedicados.
Versión Portable (.zip) Cero Permisos / Usuario Estándar

NO requiere permisos de Administrador ni elevación UAC. Puedes descomprimirlo en cualquier carpeta de usuario (Descargas, Escritorio) o en un pendrive USB y ejecutarlo de forma inmediata. No altera el Registro de Windows y almacena su estado en %APPDATA%.

Ideal para evaluadores, consultores externos y portátiles con políticas IT restringidas.

Procedimiento de Desinstalación Limpia (Certificado Softpedia)

Softpedia verificó que Bentian ERP Bridge no deja residuos en el sistema operativo tras su desinstalación:

  1. Abre Configuración de Windows > Aplicaciones > Aplicaciones instaladas (o Panel de Control > Programas y características).
  2. Localiza Bentian ERP Bridge y haz clic en Desinstalar. El asistente removerá los binarios y las asociaciones del sistema en segundos.
  3. Borrado voluntario de estado: Si deseas eliminar la configuración local y el historial de sincronizaciones, elimina voluntariamente el directorio %APPDATA%\Bentian Agent\. Cero claves huérfanas en el Registro de Windows.

5. Configuración de Red y Seguridad (Cero Puertos Entrantes)

Uno de los mayores blindajes de seguridad de Bentian ERP Bridge destacados en la auditoría de Softpedia es que NO abre ningún puerto entrante en tu router ni en el cortafuegos de Windows:

  • Puerto local de interfaz (Loopback): Escucha únicamente en la interfaz interna http://127.0.0.1:39281. Este puerto está estrictamente confinado al ordenador local y es completamente inaccesible desde la red local o desde Internet.
  • Comunicaciones salientes: Todas las sincronizaciones hacia tu tienda online (WooCommerce, PrestaShop, Shopify) y hacia la API central de licencias se efectúan como peticiones salientes seguras mediante HTTPS (Puerto 443 TCP) cifrado con TLS 1.3.
  • Cero exposición perimetral: No requiere configurar DMZ, NAT ni aperturas de puertos en el router corporativo de tu oficina o almacén.

6. Motor Relacional y Controlador OLEDB Requerido

Tanto Factusol como SimplyGest Desktop almacenan internamente su información empresarial en bases de datos relacionales Microsoft Access / Jet (.accdb o Datos.mdb). Para que el agente de Bentian interactúe con el catálogo y pedidos con arquitectura nativa de 64 bits sin depender de la GUI del ERP, el equipo debe contar con el proveedor OLEDB oficial de Microsoft:

Microsoft Access Database Engine 2016 Redistributable (64 bits)

Proporciona el proveedor relacional Microsoft.ACE.OLEDB.16.0 (o superior) compatible con Factusol y SimplyGest. Si el ERP ya se encuentra instalado en el ordenador, este controlador suele venir preconfigurado. Si el asistente inicial de Bentian reportara una alerta de OLEDB ausente, puedes instalarlo en 1 minuto de forma totalmente gratuita.
