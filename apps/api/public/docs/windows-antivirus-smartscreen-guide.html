Guía de Resolución de Windows Defender SmartScreen y Exclusiones de Antivirus

Instrucciones técnicas paso a paso para desbloquear el instalador oficial de Bentian ERP Bridge, entender el mecanismo de reputación de Microsoft y configurar las exclusiones críticas para garantizar la lectura concurrente OLEDB de Factusol sin interrupciones.

Componentes afectados: BentianAgent.exe BentianTray.exe Bentian-Setup-v*.exe cscript.exe (adodb.js)

1

¿Por Qué Aparece la Pantalla Azul de SmartScreen?

Al descargar e iniciar por primera vez el instalador oficial (Bentian-Setup-v*.exe) o el agente en equipos con Windows 10, Windows 11 o Windows Server, el sistema operativo puede mostrar una ventana de alerta azul con el mensaje:

"Windows protegió su PC" Microsoft Defender SmartScreen evitó el inicio de una aplicación no reconocida. Si ejecuta esta aplicación, su PC podría estar en riesgo.

El Mecanismo de Reputación de Microsoft SmartScreen

Microsoft Defender SmartScreen no analiza el código binario buscando virus en esta etapa: evalúa la reputación histórica acumulada de la firma digital del ejecutable.

1. Reputación vs Nuevas Versiones

Cada vez que se compila y publica una nueva versión del software (ej. v0.3.1), Microsoft la clasifica inicialmente como "de baja reputación" hasta que cientos de miles de equipos en el mundo la descargan sin incidentes. Este aviso es completamente habitual en software profesional B2B.

2. Seguridad Criptográfica Nativa

Bentian ERP Bridge incorpora un sistema criptográfico de verificación asimétrica interna con curvas elípticas Ed25519 y firmas SHA-256 auditadas. No contiene adware, telemetría invasiva ni bibliotecas de terceros opacas. El instalador es 100% limpio y seguro.

Método B Desbloqueo en Propiedades del Archivo (Windows 11 y Smart App Control)

En Windows 11 (22H2/23H2/24H2), la función Smart App Control (SAC) puede bloquear directamente archivos descargados de la web por la marca NTFS Zone.Identifier:

  1. Abre el Explorador de Archivos y localiza el instalador descargado en tu carpeta de Descargas.
  2. Haz clic derecho sobre el archivo y selecciona Propiedades (o selecciónalo y presiona Alt + Enter).
  3. En la pestaña General, dirígete a la parte inferior (sección Seguridad).
  4. Marca la casilla "Desbloquear" (Unblock).
  5. Pulsa Aplicar y luego Aceptar.
  6. Haz doble clic en el instalador: se iniciará sin ningún tipo de advertencia.

Método C Desbloqueo Automatizado vía PowerShell (Administradores de TI)

Para terminales o despliegues sin interacción gráfica, ejecuta este comando en PowerShell: 

# Eliminar el bloqueo de zona web del instalador de Bentian
Unblock-File -Path "$env:USERPROFILE\Downloads\Bentian-Setup-*.exe"
Start-Process -FilePath "$env:USERPROFILE\Downloads\Bentian-Setup-*.exe"

Exclusiones en Antivirus y EDR: Principio de Mínimo Privilegio

Principio de Mínimo Privilegio (Zero Global Exclusions) Queda terminantemente desaconsejado aplicar exclusiones globales a ejecutables del sistema operativo como cscript.exe o comodines globales de extensión como *.accdb en todo el disco duro. Los administradores de sistemas y plataformas EDR corporativas rechazan con razón tales prácticas por generar vectores de evasión. Bentian ERP Bridge se configura acotando estrictamente las exclusiones a las rutas de sus propios binarios y al directorio de datos concreto de Factusol.
¿Por qué es necesario excluir el directorio de datos de Factusol? Factusol utiliza el motor relacional Microsoft Access Database Engine (ACE/Jet OLEDB). Si el antivirus escanea en tiempo real cada microescritura en el fichero de base de datos o en el cerrojo .laccdb, Windows generará el error crítico 3045: Could not use ''; file already in use o bloqueará la facturación física en caja. Excluir el análisis en tiempo real únicamente en la carpeta de la empresa resuelve el conflicto sin desproteger el resto del equipo.
Elemento a Excluir Ruta Exacta / Ámbito Tipo de Exclusión Criterio de Seguridad EDR
Configuración del Agente %APPDATA%\Bentian Agent\ Carpeta Persistencia local de configuración y tokens cifrados.
Logs de Diagnóstico %APPDATA%\Bentian Agent\logs\ Carpeta Escritura rotativa continua de trazas operativas.
Binarios (Instalación Sistema) C:\Program Files\Bentian Agent\ Carpeta / Proceso Ejecutables firmados: BentianAgent.exe y BentianTray.exe.
Binarios (Instalación Usuario) %LOCALAPPDATA%\Bentian Agent\ Carpeta / Proceso Ruta por defecto en instalaciones sin privilegios de administrador.
Directorio de Actualizaciones %TEMP%\bentian-updates\ Carpeta Intercambio atómico y verificado de nuevas versiones (UpdateSwapper).
Directorio de Datos Factusol C:\Factusol\Datos\FS01\ o \\SERVIDOR\Datos\FS\ Carpeta Específica Únicamente la carpeta de la empresa. Prohibido excluir *.accdb global.
Subproceso OLEDB (EDR) Regla contextual: Parent=BentianAgent.exe Regla EDR / IOA Autoriza cscript.exe únicamente cuando el proceso padre es el agente.
Arquitectura de Red para Administradores de Seguridad y Firewall

Bentian ERP Bridge ha sido auditado para operar bajo las políticas de seguridad perimetral más estrictas de infraestructuras corporativas:

  • Conexiones exclusivamente salientes: Todo el tráfico se emite mediante peticiones salientes seguras HTTPS sobre el puerto TCP 443 hacia el endpoint del eCommerce del cliente (WooCommerce, PrestaShop o Shopify) y hacia la API central de Bentian (bridge.cristianjm.com).
  • Cero puertos entrantes abiertos: El agente no abre ningún puerto de escucha hacia internet ni hacia la red local LAN. No requiere NAT, reglas de port forwarding ni DMZ en el router perimetral.
  • Aislamiento de la Interfaz Web Local: La interfaz gráfica de administración del agente escucha de forma inmutable y exclusiva en la dirección de bucle invertido 127.0.0.1:39281, impidiendo cualquier acceso remoto desde otros puestos de la red.

Instrucciones Específicas por Suite Antivirus

4.1 Microsoft Defender Antivirus (Seguridad de Windows)

Abre una consola de PowerShell como Administrador y ejecuta el script configurado con el Principio de Mínimo Privilegio: 

# 1. Excluir directorios específicos de Bentian Agent
Add-MpPreference -ExclusionPath "$env:APPDATA\Bentian Agent"
Add-MpPreference -ExclusionPath "$env:APPDATA\Bentian Agent\logs"
Add-MpPreference -ExclusionPath "C:\Program Files\Bentian Agent"
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\Bentian Agent"
Add-MpPreference -ExclusionPath "$env:TEMP\bentian-updates"

# 2. Excluir procesos ejecutables de Bentian por ruta específica
Add-MpPreference -ExclusionProcess "C:\Program Files\Bentian Agent\BentianAgent.exe"
Add-MpPreference -ExclusionProcess "C:\Program Files\Bentian Agent\BentianTray.exe"
Add-MpPreference -ExclusionProcess "$env:LOCALAPPDATA\Bentian Agent\BentianAgent.exe"
Add-MpPreference -ExclusionProcess "$env:LOCALAPPDATA\Bentian Agent\BentianTray.exe"

# 3. Excluir ÚNICAMENTE el directorio de datos de Factusol (ajusta a la ruta real de tu empresa)
# NOTA: NUNCA añadir exclusión global de la extensión *.accdb ni de cscript.exe
Add-MpPreference -ExclusionPath "C:\Factusol\Datos\FS01"
# Si la base de datos se encuentra en un servidor o NAS en red local:
# Add-MpPreference -ExclusionPath "\\SERVIDOR\Datos\FS01"

Write-Host "✓ Exclusiones de Mínimo Privilegio aplicadas con éxito en Windows Defender." -ForegroundColor Green
Vía Interfaz Gráfica: Seguridad de Windows → Protección contra virus y amenazas → Administrar la configuración → Exclusiones → Agregar o quitar exclusiones → Agregar Carpetas específicas y Procesos por ruta completa.

4.2 Kaspersky (Endpoint Security / Small Office / Plus)

  1. Abre Kaspersky y pulsa en el icono de Configuración (engranaje).
  2. Entra en Configuración de seguridad → Exclusiones y aplicaciones de confianza.
  3. En Exclusiones, pulsa Agregar y añade únicamente las carpetas específicas:
    • C:\Program Files\Bentian Agent\*
    • %LOCALAPPDATA%\Bentian Agent\*
    • %APPDATA%\Bentian Agent\*
    • Carpeta de datos de Factusol (ej: C:\Factusol\Datos\FS01\* o \\SERVIDOR\Datos\FS01\*)
  4. En Aplicaciones de confianza, añade por ruta completa BentianAgent.exe y BentianTray.exe.
  5. Marca: "No supervisar la actividad de la aplicación" y "No heredar restricciones del proceso principal" para dichos ejecutables.
  6. Pulsa Guardar.

4.3 Bitdefender (GravityZone Cloud / Total Security)

  1. Abre Bitdefender y dirígete al módulo Protección → Antivirus → Ajustes / Exclusiones.
  2. Pulsa Añadir exclusión: selecciona carpeta y añade C:\Program Files\Bentian Agent, %APPDATA%\Bentian Agent y la carpeta específica de datos de Factusol (marcar "En acceso y Bajo demanda").
  3. En Defensa contra amenazas avanzadas (ATD): añade a la lista de excepciones BentianAgent.exe y BentianTray.exe por su ruta absoluta.
  4. En consolas corporativas GravityZone, crea la exclusión de antimalware asociada a la ruta de datos concreta del ERP sin añadir comodines de extensión global.

4.4 Avast Antivirus & AVG AntiVirus (Motor Gen Digital)

Muy Común en PYMEs

Avast y AVG comparten el mismo motor de escudos en tiempo real (File Shield y Behavior Shield). Configura las excepciones de ruta específica para evitar bloqueos del conector:

  1. Abre la interfaz principal de Avast o AVG.
  2. Haz clic en Menú (esquina superior derecha) → Opciones (o Configuración).
  3. En la pestaña General, selecciona la subsección Excepciones.
  4. Haz clic en el botón Añadir excepción y agrega una por una las siguientes rutas específicas:
    • C:\Program Files\Bentian Agent\*
    • %LOCALAPPDATA%\Bentian Agent\*
    • %APPDATA%\Bentian Agent\*
    • %TEMP%\bentian-updates\*
    • La carpeta de datos de la empresa de Factusol (ej. C:\Factusol\Datos\FS01\* o \\SERVIDOR\Datos\FS01\*)
  5. En el menú lateral, dirígete a Protección → Escudo contra ransomware:
    Entra en Aplicaciones bloqueadas y permitidas. Asegúrate de autorizar BentianAgent.exe y BentianTray.exe por su ruta de instalación.
  6. Reinicia el agente desde el icono del System Tray.

4.5 CrowdStrike Falcon EDR (Entornos Corporativos)

Falcon Sensor vigila invocaciones sospechosas de Living off the Land (LotL). Para silenciar la alerta del subproceso COM OLEDB respetando el Principio de Mínimo Privilegio, se define una regla condicional que autoriza la ejecución únicamente cuando el proceso padre es el agente legítimo ejecutando el script oficial del conector:

Regla Custom IOA Exclusion (Principio de Mínimo Privilegio):
Parent Image Filename: .*\\BentianAgent\.exe
Image Filename: .*\\cscript\.exe
Command Line: .*adodb\.js.*
Action: Allow / No Alert

De este modo, cualquier otra llamada a cscript.exe ajena a Bentian continúa siendo interceptada y analizada con normalidad por Falcon.

Verificación de Funcionamiento tras Aplicar Exclusiones

  1. Comprueba que el icono de Bentian ERP Bridge aparece en la bandeja del sistema (junto al reloj de Windows).
  2. Haz clic derecho sobre el icono y selecciona Abrir Panel de Control.
  3. Verifica que el estado de conexión con Factusol se muestra en color verde (En Línea / Conectado).
  4. El archivo de registro en %APPDATA%\Bentian Agent\logs\agent.log debe confirmar la conexión OLEDB limpia:
[INFO] [FactusolService] Conexión OLEDB con base de datos establecida correctamente.
[INFO] [FileWatcher] Monitor de cambios en *.accdb activo.
