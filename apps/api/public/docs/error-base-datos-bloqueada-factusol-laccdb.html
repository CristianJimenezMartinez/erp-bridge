Cómo Solucionar el Error de Base de Datos Bloqueada (.laccdb) en Factusol

Uno de los problemas más habituales al trabajar con Factusol en red local o en un servidor NAS (Synology, QNAP, Windows Server) es el bloqueo imprevisto de la base de datos (Error 3045: "El archivo ya está en uso por otro proceso o usuario"). En esta guía técnica explicamos por qué ocurre y cómo resolverlo sin peligro de corrupción.

1. ¿Qué es el archivo .laccdb (o .ldb)?

Factusol utiliza como motor relacional Microsoft Access (ACE / Jet OLEDB). Cada vez que un usuario abre una empresa en Factusol (ej: 2262026.accdb), el motor de base de datos crea de forma automática en la misma carpeta un archivo complementario con el mismo nombre y extensión .laccdb (o .ldb en versiones antiguas).

Este archivo registra qué ordenador de la red está conectado para coordinar los bloqueos de registro. Si un equipo se apaga bruscamente, entra en suspensión, sufre un microcorte de Wi-Fi o un conector externo se cierra de forma inesperada, el archivo .laccdb queda huérfano y Windows sigue marcando la base de datos como "ocupada exclusivamente", impidiendo que nadie pueda entrar.

2. Pasos para Desbloquear la Base de Datos

1

Cerrar Factusol en todos los puestos de la oficina

Pide a todos los usuarios de la red local que cierren completamente el programa Factusol. Comprueba en el Administrador de Tareas (Ctrl + Mayús + Esc) que ningún proceso huérfano (FACTUSOL.exe o cscript.exe) continúe ejecutándose en segundo plano.

2

Liberar archivos abiertos en el Servidor o NAS

Si la base de datos reside en un servidor Windows o en un NAS:

  • En Windows Server: Abre compmgmt.msc (Administración de equipos) → Carpetas compartidas → Archivos abiertos. Busca el archivo .laccdb, haz clic derecho y selecciona Cerrar archivo abierto.
  • En Synology / QNAP: En el Panel de Control → Servicios de archivo → Administrador de conexiones SMB, desconecta la sesión residual del equipo cliente.
3

Eliminar el archivo de bloqueo huérfano (.laccdb)

Una vez verificado que ningún equipo tiene el programa abierto, accede a la carpeta de datos de Factusol (ej: \\NAS\Datos\FS\) y elimina manualmente el archivo con extensión .laccdb (o .ldb). ATENCIÓN: Elimina ÚNICAMENTE el archivo .laccdb de pocos kilobytes, jamás el archivo principal .accdb.

4

Revisar permisos de red de la carpeta compartida

Para que Factusol pueda crear y destruir el archivo .laccdb sin errores, todos los usuarios de la red necesitan permisos completos de Lectura, Escritura, Modificación y Eliminación en la carpeta compartida. Si un usuario carece de permiso de eliminación, el archivo de bloqueo no se borra al salir y causa bloqueos recurrentes.
