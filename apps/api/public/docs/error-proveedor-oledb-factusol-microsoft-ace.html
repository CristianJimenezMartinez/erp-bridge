Resolución de Incidencias • Drivers OLEDB y Access Database Engine

Solución al Error: "El proveedor Microsoft.ACE.OLEDB no está registrado en el equipo local"

Este error es el obstáculo más común cuando un informático, programador o agencia intenta conectar una tienda online o una aplicación externa con la base de datos de Factusol (.accdb). A continuación explicamos por qué sucede el conflicto de arquitectura y cómo repararlo de forma definitiva.

1. ¿Por qué ocurre este error?

Factusol almacena sus datos en formato Microsoft Access. Para leer y escribir en estos archivos sin tener abierto el programa Factusol, Windows requiere una librería del sistema llamada Microsoft Access Database Engine (ACE OLEDB).

El error se produce por una incompatibilidad de arquitectura (32 bits vs 64 bits):

  • Factusol históricamente corre como proceso de 32 bits (x86).
  • La mayoría de ordenadores modernos con Windows 10 u 11 ejecutan sistemas y entornos de ejecución de 64 bits (x64).
  • Si tu aplicación o script (Node.js, Python, C#, PHP) se ejecuta en 64 bits, buscará la DLL de 64 bits de Microsoft.ACE.OLEDB.12.0 o 16.0. Si Windows solo tiene registrados los componentes de 32 bits de Microsoft Office, arroja la excepción inmediata.

2. Cómo Solucionarlo Paso a Paso

1

Descargar Microsoft Access Database Engine Redistributable

Descarga el paquete oficial desde la web de Microsoft:

  • Microsoft Access Database Engine 2016 Redistributable (oficial de Microsoft).
  • Descarga el archivo accessdatabaseengine_X64.exe (para entornos de 64 bits) o accessdatabaseengine.exe (32 bits).
2

Instalación en Modo Silencioso (/quiet)

Si tienes instalado Office en 32 bits e intentas instalar los drivers de 64 bits mediante doble clic, el instalador de Microsoft mostrará un mensaje bloqueante: "No se puede instalar la versión de 64 bits de Access Database Engine porque tiene productos de Office de 32 bits".

Para saltarte esta restricción innecesaria y registrar el proveedor OLEDB correctamente:

# Abre CMD o PowerShell como Administrador y ejecuta:
accessdatabaseengine_X64.exe /quiet
3

Verificar la Cadena de Conexión (Connection String)

Asegúrate de que tu cadena de conexión utilice la versión registrada en el sistema:

Provider=Microsoft.ACE.OLEDB.12.0;Data Source=C:\Datos\FS\2262026.accdb;Persist Security Info=False;Mode=Share Deny None;
