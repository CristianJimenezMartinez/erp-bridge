03

Software y Dependencias

  • •
    Factusol ERP: Compatible con todas las versiones anuales desde Factusol 2018 hasta 2026+. Soporta formatos relacionales .accdb (Access 2016-2024/365) y bases de datos históricas .mdb.
  • •
    Microsoft Access Database Engine: Incluido de forma predeterminada con la propia instalación de Factusol en el equipo. En caso de ausencia, es descargable gratuitamente desde la web de Microsoft (versión x64 recomendada).
  • •
    Microsoft Edge WebView2 / .NET 4.8: Integrado de serie en Windows 10 y Windows 11 para la renderización de la ventana de interfaz nativa en modo app independiente.
04

Permisos de Ejecución en Windows

Usuario Estándar de Windows: Bentian ERP Bridge está diseñado para operar con los privilegios de un usuario común sin requerir permisos de Administrador para su ejecución en segundo plano, sincronización ni acceso a la bandeja del sistema (System Tray).

✓ Configuración en perfil del usuario activo (%APPDATA%).
✓ Cero problemas de UAC durante el ciclo diario.
✓ No modifica archivos críticos de Windows ni inyecta drivers de kernel.
05

Requisitos de Red & Firewall

  • •
    Conexión Saliente Exclusiva: Tráfico saliente a través del puerto TCP 443 (HTTPS) con cifrado TLS 1.2 / TLS 1.3 hacia tu eCommerce y hacia la API de licencias.
  • •
    Cero Puertos Entrantes: No requiere abrir puertos en el router, ni configurar DMZ, ni mapear puertos NAT hacia el equipo de la oficina.
  • •
    Servidor Local Administrativo: Escucha únicamente en la interfaz de bucle invertido 127.0.0.1:39281 con puerto fijo inmutable y cerrojo anti-bifurcación.
06

Desinstalación Limpia Garantizada

Bentian incluye un desinstalador nativo estándar de Windows accesible desde Configuración > Aplicaciones instaladas o el Panel de Control tradicional.

✓ Elimina binarios, accesos directos y servicios de forma pulcra.
✓ Seguridad sagrada: NUNCA toca, borra ni altera tu base de datos de Factusol.
✓ Deja el registro de Windows completamente limpio sin restos huérfanos.
