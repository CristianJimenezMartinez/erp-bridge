# Resumen Ejecutivo & Boilerplate

Texto Oficial para Citar

Bentian ERP Bridge es una solución de conectividad y sincronización local-first de alto rendimiento que conecta sistemas de gestión empresarial de escritorio —como Factusol y SimplyGest— con plataformas de comercio electrónico líderes como WooCommerce, PrestaShop y Shopify.

Diseñado bajo el principio de Zero-Knowledge y Soberanía Total de Datos, Bentian ERP Bridge prescinde de nubes intermedias que retengan bases de datos de clientes y no requiere la apertura de puertos de entrada en el router. Su agente ligero de Windows procesa los deltas de stock mediante lectura directa OLEDB sin provocar bloqueos de archivo (evitando el infame Error 3045), calcula existencias reales disponibles (fórmula DISSTO) y garantiza la inyección transaccional de pedidos con tolerancia a desconexiones (Store-and-Forward persistente).

Modelo de Arquitectura
Local-First & Cero Puertos

Conexión saliente cifrada TLS 1.3 sin exponer la red empresarial a escaneos externos.

Integridad Transaccional
Buffer Store-and-Forward

Garantía total de cero pedidos perdidos ante cortes de red o reinicios imprevistos.

Sistemas Operativos Windows 10, 11, Windows Server (2016-2025) Compatibilidad nativa con arquitecturas de 64-bit (x64)
Huella de Memoria (RAM) < 35 MB en reposo / < 90 MB en carga alta Optimizaciones con buffers en streaming sin retención de GC
Puertos de Red de Entrada 0 puertos WAN abiertos Toda la sincronización se realiza en sentido saliente HTTPS (TLS 1.3)
Control de Bloqueos OLEDB Modo solo lectura no bloqueante (.laccdb free) Eliminación completa del Error 3045 en Factusol
Cálculo de Stock Fórmula DISSTO en RAM por hash SHA-256 Descuento automático de pedidos pendientes y reservas online
Cifrado de Credenciales Windows Data Protection API (DPAPI) Claves protegidas por el subsistema criptográfico local de Windows
Firmas de Actualización Ed25519 (RFC 8032) + SHA-256 Verificación asimétrica previa a la sustitución atómica de binarios
