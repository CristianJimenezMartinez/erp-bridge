## 1. EL PROBLEMA QUE DESBLOQUEA BENTIAN PARA TU AGENCIA O CONSULTORA

Cuando una agencia web o un Agente Digitalizador cierra un proyecto de comercio electrónico (WooCommerce, Shopify o PrestaShop) para un distribuidor, ferretería, tienda de recambios o comercio minorista, siempre aparece el mismo muro técnico:

> **"El cliente tiene su catálogo, precios, fotos y stock dentro de Factusol, SimplyGest, Sage 50, a3ERP o Ágora POS en un ordenador Windows local en el almacén."**

Hasta hoy tenías dos malas opciones:
1. **Desarrollar un conector a medida o pelearte con plugins PHP antiguos:** Perder semanas de horas de programación que se comen todo el margen del proyecto (o del bono de Kit Digital) y quedarte atado a dar soporte cada vez que se bloquea la base de datos del cliente.
2. **Proponer conectores cloud de terceros de 150 €/mes + 2.500 € de alta:** El cliente PYME rechaza el presupuesto por caro y el proyecto se estanca.

### Cómo cambia tu negocio con Bentian ERP Bridge
Con Bentian instalas un **Agente Nativo Windows Local-First** en el equipo del cliente en **menos de 15 minutos**:
- **5 ERPs Locales + Holded Cloud en un único Agente:** Soporta nativamente **Factusol** (`.accdb`/`.mdb`), **SimplyGest** (triple motor: DBISAM `Emp1\articulos.dat`, Server API `:56985` y `Datos.mdb`), **Sage 50** (auto-detección de ejercicio `2026XX` + `guid_id`), **Wolters Kluwer a3ERP** (ActiveX COM `a3ERPActiveX.Pedido` + SQL `IDPEDV`) y **Ágora Retail / POS** (SQL + API HTTP `:8984`).
- **Fotos 100% Automáticas (`UniversalErpImageResolver`):** Extrae y sube las fotos de los productos directamente desde las carpetas locales/NAS o los campos binarios SQL (`VARBINARY`/`IMAGE`) del ERP con deduplicación `SHA-256`. Te ahorras días enteros pidiendo fotos al cliente para montar la tienda.
- **Modo Evaluación Sandbox (Cero Riesgo ante el Informático del Cliente):** Permite simular toda la lectura de catálogo y la inyección de pedidos en seco sin escribir un solo byte en la base de datos real hasta que todo está validado.
- **Sin abrir puertos en el router:** Todo funciona mediante tráfico saliente HTTPS (`TLS 1.3`). No tienes que pelearte con el informático del cliente por IPs fijas, VPNs o puertos expuestos.
